# DRAGEN Tool Colours

CSS colours for DRAGEN tools, used for the tool pills in
[`nemo::nemo_schema_reactable()`](https://tidywf.github.io/nemo/reference/nemo_schema_reactable.html).
Other tools fall back to grey.

## Usage

``` r
DRAGEN_TOOL_COLOURS
```

## Format

An object of class `character` of length 8.
