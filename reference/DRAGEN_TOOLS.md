# DRAGEN Tools Supported

List of all tools the
[Dragen](https://tidywf.github.io/tidydragen/reference/Dragen.md)
workflow runs: the DRAGEN pipeline tools plus
[Interop](https://tidywf.github.io/tidydragen/reference/Interop.md).

## Usage

``` r
DRAGEN_TOOLS
```

## Format

An object of class `list` of length 8.
